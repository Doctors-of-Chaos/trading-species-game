新手模式是**六道"真实暴富瞬间"选择题**（无K线门槛），进阶模式是**隐藏指数/年份的盲盒行情赌局**；

## 3. 当前功能清单（均已实测）

### 新手模式 · 六次暴富的机会摆在桌上
- 无 K 线、无术语门槛；每关一段场景故事 + 一个"这一万元，你怎么花？"选择题
- 六个真实瞬间：2008 北京楼市 / 2010 比特币 / 2015 显卡(英伟达) / 2004 腾讯IPO / 2020 封城恐慌 / 2021 元宇宙狂热
- 每选项对应真实历史倍数（×923、×290、×1.6、×0.4、错过=0 递进展示）
- 全程钱包连续结算（神话级倍数封顶防溢出），6关结束生成人物卡

### 进阶模式 · 无名行情赌局
- 从 15 个真实历史窗口（三个指数 × 不同年份）随机抽取
- 指数名、年份、日历全部隐藏，只给量价事实
- 揭晓时亮"底牌"（真实坐标），供复盘验证判断

### 共用产出 · 交易人物卡
- 四维雷达（风险承受/纪律性/逆向冷静/引导需求），纯行为数据反推，非自我评价
- 稀有度 R/SR/SSR、徽章（🚀满仓信仰 / 🧊冰水浇头 / ⏳等等党 / 🖐用户直觉 …）
- 钱包结局（乱世暴富 / 阶层击穿 / 全身而退 / 学费交了不少）
- 因人而异的下一步推荐：数据/工具/任务三类，挂真实数据接口名

## 4. 赛题对标

| 赛题要求 | 覆盖方式 |
|---|---|
| 有趣的互动体验 | 新手模式 3 分钟内完成，选择题零门槛；进阶模式有盲盒悬念 |
| 有依据、可修正的画像 | 全程行为数据（选择/用时/求证方式）→ 雷达证据列表；能力与偏好分离，收益非唯一标准 |
| 连接下一步的个性化推荐 | 四物种×三资源，推荐理由绑定刚才的游戏行为 |
| 合理运用真实数据 | akshare 新浪接口拉取真实日线；盲盒区分"决策时可见"与"后续揭晓" |

## 5. 已知限制（诚实清单）

- 画像规则引擎（DELTA 表）是**手上拍的**，参赛作品应换成回归/聚类等可解释模型
- 神话倍数（比特币）在钱包结算中被人为封顶，只作荣誉徽章，不是严格数值模拟
- 盲盒池只有 15 窗口/3 指数，正式版应扩展到全市场随机采样
- 无用户会话持久化（刷新即丢），正式版需接后端档案
- 单机demo，未接 PandaData SDK / QuantSkills 生产环境（赛题明确允许）
