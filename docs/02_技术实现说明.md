# 02 · 技术实现说明

> 实现载体：单文件 HTML（fragment 源码 → 渲染后 standalone）。无后端、无依赖安装。

## 1. 数据管线（真实历史数据来源）

| 数据块 | 拉取方式 | 用途 | 存档 |
|---|---|---|---|
| 沪深300 日线 2002–2026 | `akshare.stock_zh_index_daily("sh000300")` ~6000 行 | 序章3幕 + 数据概览校验 | data_hs300_windows.json |
| 上证50/中证500/创业板指 | `akshare.stock_zh_index_daily("sh000016"/"sh000905"/"sz399006")` | 盲盒池窗口切样 | data_blindbox_pool.json |
| 英伟达/腾讯 未复权收盘价 | `akshare.stock_us_daily("NVDA")` / `stock_hk_daily("00700")` | 新手模式故事倍数锚点 | 内嵌于故事题（×290 / ×923，含拆股换算） |
| 北京房价/比特币/黄金 | 公开常识锚点（故事化处理，非逐日数据） | 新手模式 | 内嵌 |

**盲盒池切样规则**：对每个指数，从第 130 个交易日开始，每 130 个交易日取一窗（55 日可见 + 30 日揭晓），形成候选；每指数保留 ≤6 个、洗牌后共 15 个。关键约束：**决策日行为只用可见窗口数据；揭晓仅发生在提交后**——对应赛题"区分玩家当时可见的信息与后续结果"。

## 2. 画像引擎（行为 → 四维）

维度：`press`(风险承受) / `disc`(纪律性) / `rev`(逆向冷静) / `need`(引导需求)，初始 50，逐题加减后 clamp 0–100。

- **进阶模式**：`DELTA[code][仓位]` 查表（行为处清洗后的设计值）+ `META_DELTA[求证方式]`。
- **新手模式**：按六题的故事选项 key 映射（如 `contra`(逆势进场)→rev+8、`fomo`(追热点)→disc−8/rev−6、`coop`/`ask`(找人商量)→need+8）。
- 边界地带检测：维度值贴近阈值 ±7 时输出"临界"提示（如"你处在两种物种交界"）——对应赛题"一次选择不足以定义一个人"。
- 决策用时全程记录并印在结尾卡上（犹豫/急躁都是信号）。

物种定位：press≥52=进取 / 稳健 × need≥50=引导 / 独立 → 猎豹/大象/狐狸/熊猫。

## 3. 游戏化层

- **钱包连续结算**：新手模式 10000 起步，每关乘以该选项的 kicker 倍数；倍数 ≥1000（神话级）封顶 ×1000 并记入 `st._jackpots`，卡面显示"👑 神话级机会 n 连中"，防数值溢出为荒谬大数。
- **稀有度**：SSR = press>70 或 disc<35（极端打法），SR = press>58 或 disc<42，其余 R。
- **徽章**：全部从实际行为 mined：
  - 通用：⚡手快(单题<5s)、🎯敢重仓、🛡风控大师(≥2次空仓)、🔬数据控、🧭跟队型、🔥上头型
  - 新手专属：🚀满仓信仰 / 🧊冰水浇头 / ⏳等等党 / 🖐用户直觉 / 👑神话级机会
- **结局**：钱包结果 label（史上最强裂缝穿越者 / 阶层击穿 / 乱世暴富 / 安稳增值 / 全身而退 / 学费交了不少），金额以"万/亿"缩写展示。

## 4. 推荐引擎（赛题"连接下一步"）

4 物种 × 3 资源表（数据/工具/任务），每条推荐引用真实工具名（get_lhb_list / get_index_indicator / get_future_basis 等），并在卡面上保留"物种切换"按钮——同一行为数据切物种会看到完全不同的推荐包，直观演示"推荐因人而异"。

## 5. 关键实现细节（改代码前必读）

1. **fragment 是唯一真源**：`trading-species-game-fragment.html`（`#tsp-root` 包裹 + `<script>` IIFE，内嵌全部数据 JSON）。
   standalone 由 `visualize` 插件的 `scripts/render.py` 渲染导出（内嵌 css/lucide/d3 资源 base64）。
   如丢了渲染工具，直接把 fragment 包进最小 HTML 骨架 + 从 CDN 拉样式，也能双击打开。
2. **数据注入方式**：页面主脚本里 `var DATA = {...};`（序章）与 `var POOL = {...};`（盲盒池）为生成时注入的 JSON 内联体，替换数据即换题库，不用改逻辑。
3. **故事模式渲染分支**：`renderRound(i)` 开头判 `st.mode==='story'` 即转 `renderStoryRound`；`reveal` 同理走 `revealStory`。K 线图区域在该模式下 `display:none`，剧情绪事注入 `#tsp-storybox`。每关渲染前必须先移除旧 `#tsp-storybox`/`#tsp-storyq`（实测踩过的残留 bug）。
4. **钱包防溢出**：`kicker >= 1000` 走神话分支（×1000+徽章），`kicker === 0` 表示"机会飞走"（钱包不变，不乘）。语义在代码注释里。
5. **已知遗留**：
   - 自动化测试（Playwright 高层 locator 注入 iframe）偶发 `unable to attach frame target`，与游戏本身无关；人工点击无此现象。
   - 人物卡结局线只取钱包一个数，正式版应结合回撤路径。
