# 演示视频分镜脚本（3–5 分钟）

目标：让评委在 4 分钟内看到「互动 → 画像 → 推荐 → 下一步」全流程，并亲眼看到**两条路径产生不同画像与推荐**。

## 录制准备

- 用 **iPhone 控制中心录屏**（设置 → 控制中心 → 屏幕录制；录时关闭通知）或 Mac Chrome 无痕窗口 + QuickTime（文件 → 新建屏幕录制，选内建麦克风讲口播）。
- 建议手机实机录：更贴近评委视角；若用电脑，开 Chrome DevTools 手机模拟（390×844）或直接桌面版。
- 开始前杀掉后台浏览器标签，从首页干净开始；录制中**手指操作放慢半拍**，让画面跟得上口播。
- 可以先录操作、后补口播，用剪映/iMovie 拼接；两段结算页可用分屏或前后对比。
- 录完自查：手机上小字是否看得清？口播和画面是否对齐？

## 分镜

| # | 时长 | 画面 | 操作 | 口播要点（可直接照读） |
|---|---|---|---|---|
| 1 开场 | 0:00–0:25 | 首页（标题、四个物种头像滚动） | 停留首页，滑动展示 | 「这是《交易物种》：不用答题问卷，把你放回 2004、2008、2010……六个真实投资路口，你的每个选择都会暴露你是哪种交易者。一万元本金，约三分钟。」 |
| 2 路径A | 0:25–1:10 | 新手模式 6 关 | 每关选**激进**项：开户买入 → 交定金 → 全仓买入 → 赌 AI → 逆势进场 → 上车！每关等"倒带"揭晓再点下一关，节奏可稍快 | 「第一位玩家风格激进：腾讯直接开户、比特币全仓、暴跌时逆势进场。注意页面只给他看**当时**能看到的行情和新闻，结果要等倒带才揭晓。」 |
| 3 结算页A | 1:10–2:00 | 结算页（猎豹 SSR） | 从上往下慢慢滑：人物卡 → 雷达图 → 数值条 → 「判断有多稳」→ 停在追问上点一题 → 推荐卡和理由 | 「结算：猎豹，风险承受 96。重点是这里——『判断有多稳』。引导需求只有一个选择反映，系统不装懂，直接说把握低，并给了道追问题。答完画像和物种会实时修正。推荐三卡也完全按 96 分和 45 分生成，龙虎榜数据卡还带着能直接跑的 panda_data 代码。」 |
| 4 路径B | 2:00–2:35 | 新手模式重来 | 每关选**稳健**项：不碰新股 → 拉人合资 → 关掉网页 → 买白马股 → 现金为王 → 问问朋友（同样等揭晓） | 「第二位玩家完全相反：不碰新股、先问朋友、现金为王。同样的六个路口，不同的行为。」 |
| 5 结算对比 | 2:35–3:20 | 结算页B（熊猫 R），可与 A 分屏 | 滑到四维数值（28/50/50/69）停一停 → 「判断有多稳」两条都把握高、**没有追问** → 推荐卡 → 点「换个物种看看」切到猎豹再切回 | 「熊猫，风险承受 28、引导需求 69，两条判断都把握高，所以没有追问——证据足就不打扰。推荐也换成了学习卡加虚拟盘：给激进者的龙虎榜，不会推给怕回撤的人。点『换个物种看看』，推荐确实跟着画像走。」 |
| 6 进阶+数据 | 3:20–4:00 | 进阶模式盲盒 | 进一个盲盒：看 K 线选仓位和决策依据 → 揭晓；口播提数据来源 | 「进阶模式是 15 段隐去名称和年份的真实行情。15 段里 13 段共 1105 根 K 线，我们用 Panda Data 逐日核对过收盘价；未核对的两个和故事化数字，页面里都明确标了『估算』。」 |
| 7 收尾 | 4:00–4:25 | 回到首页或结算页底部 | 滑到底部隐私说明 | 「全程零网络请求、不存任何数据，收益只讲故事、不进画像。这就是《交易物种》——认识用户，从一场游戏开始。」 |

## 注意

- 两路径的期望结果（对照检查，不符则重录）：A = 猎豹 SSR、四维 96/51/52/45、**出现追问**；B = 熊猫 R、28/50/50/69、**无追问**。
- 若时间超 5 分钟：优先压缩 #2/#4 的过程镜头（可剪辑跳切），保住 #3/#5 结算页对比的完整度。
- 录屏中出现的示例代码、标注文字保持清晰，这是"示例资源已标注"的合规证据之一。
