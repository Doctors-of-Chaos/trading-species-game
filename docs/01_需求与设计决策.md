# 01 · 需求演进史：每次"不行"背后的设计翻转

> 记录用户在本对话中的 4 轮关键反馈与每轮的设计调整。供评审理解"游戏为什么长这样"，也供后续迭代不再回退。

## V1 · 初版：三回合固定行情（9·24 / 疫情熔断 / 狂热顶）

- 出发点：用真实历史"名场面"测追涨/抄底/止盈三种决策习惯。
- 数据：akshare 拉沪深300日线，只显示决策日之前，提交后揭晓后续走势。
- 产出：四物种画像 + 推荐包 + 物种切换演示。

**用户反馈 ①**："都是我了解后续市场变化的名场面，对老鸟不行。"

## V2 · 盲盒模式：隐藏一切可检索锚点

- 加入 15 窗口抽签池（上证50/中证500/创业板指），指数名、年份、日历全隐藏，只给量价事实。
- 揭晓时亮"底牌"（真实坐标）→ 老鸟的乐趣从"猜中"变成"复盘验证"。
- 实测修 bug：底牌日期解析错位、收尾按钮不触发。

**用户反馈 ②**："太硬核，老鸟能玩，但完全不懂的人为什么要玩？要站在游戏角度，不是专业投资者角度。"

## V3 · 剧情模式：时光机与一万元

- K 线藏进故事里：捡到时光机回到某天，口袋一万元，只回答"买多少"。
- 数值反馈从"净值+14.7%"改成"钱包 ¥11,472"这种具体数字。
- 结尾从"画像报告"升级成"交易人物卡"：稀有度 + 徽章 + 结局 label。

**用户反馈 ③**："还是不行。新手模式要用普通人都知道的暴富途径吸引人（08年买房、08年买币、24年买英伟达这种）；而且不能上来就K线——对投资没兴趣的人不会玩。"

## V4 · 终版：把"K线游戏"整个换成"人生瞬间选择题"

核心翻转：**游戏的钩子不是行情，是每个人都听说的暴富故事**。
- 六道真实暴富场景，全部为纯文字场景 + 4 选项选择题：
  2008 北京一万六地铁房 / 2010 0.08美元比特币 / 2015 显卡摊位(英伟达) / 2004 腾讯IPO / 2020 封城恐慌饭桌 / 2021 元宇宙狂热咖啡馆
- 决策指标从"仓位比例"换成"人生选择"：All in / 等等党 / 问朋友 / 关网页
- 钱包 是唯一的连续反馈：×923、×290、错过显示"机会飞走了"
- K 线与盲盒整体后移为"进阶模式"，入口明确标注"老鸟挑战"
- 画像引擎不变：两种模式都在喂同一个四维雷达

## 设计原则沉淀

1. **钩子分层**：新手被"暴富故事"吸引（人人都听过的故事无门槛），老鸟被"盲盒+复盘"吸引。
2. **单文件交付**：一个 HTML 片段承载全部逻辑与数据，方便转发/评审/复用。
3. **行为 > 自评**：任何题目都不允许用户自我描述；哀时间、犹豫、求证方式都是信号。
4. **揭晓即钩子**：每关结束都给"如果当时……"真实对照，强化重玩动机。
5. **神话封顶**：数值乐趣不能变成数值荒谬（比特币 ×2 亿连乘会溢出）；荣誉用徽章表达而非数字。

## 和其他 AI 的对比视角（给评审的提示）

看别的作品时值得对照检查这几个反向问题：
- 有没有一开始就把选择题包在 K 线里（导致非投资者流失）？
- 画像是不是"问卷答案的转述"而非"行为证据的归纳"？
- 推荐是不是看不出"因为上面第 3 题你选了 X 所以推荐 Y"？
- 数据是否区分了"决策时可见"与"事后揭晓"（防上帝视角）？
