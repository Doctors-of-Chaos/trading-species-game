# 交易物种游戏

PandaAI「苏客松」参赛原型：单文件网页游戏。玩家在历史路口做选择，系统生成「交易物种」人物卡，并给出因人而异的下一步推荐。

## 本地运行

下载后双击 `index.html`，用 Chrome 打开即可。无需联网，无需安装。

## 两种模式

- 新手模式：6 个真实历史路口（2004 腾讯上市、2008 北京楼市、2010 比特币、2015 英伟达、2020 疫情暴跌、2021 元宇宙热潮），选图标卡片。
- 进阶模式：5 个隐藏指数名与年份的行情盲盒，选仓位与决策依据。

结算页包含：

- 人物卡：猎豹、大象、狐狸、熊猫四种物种
- 四维画像：风险承受、纪律性、逆向冷静、引导需求
- 「判断有多稳」：证据不足时可再答一题修正判断
- 示例推荐：附 `panda_data` 接口示例代码

## 数据核对情况

- 盲盒行情为内置静态数据，最初来自 akshare。已与 Panda Data 指数日线逐日对照：15 个窗口中 13 个（1105 根 K 线）完全一致；另 2 个窗口（2004 上证50、2008 中证500）早于 2010 年，尚未对照。
- 2020 年沪深300（2 月 3 日 3688 点到年底 5211 点，+41.3%）已用 Panda Data 核对一致。
- 英伟达：Panda Data 复权数据显示 2015 年初到 2024 年末约 278 倍，页面仍写「约 290 倍」，待修改。
- 腾讯「约 920 倍」尚未核对。
- 2010 比特币、2008 北京房价不在 Panda Data 范围内，倍数为故事化估算，页面已注明；单关最多按 ×1000 结算。
- 倒带曲线是示意动画，不是逐日行情，页面已标注。
- 推荐代码取自 `panda_data` 官方文档示例，其中 4 个接口已用真实账号跑通；推荐内容标注为「示例推荐」，未接入生产环境。

## 已知限制

- 只在 Chrome（桌面与手机宽度）测试过，Safari、Firefox、真机未测。
- 部分图标使用系统 emoji，不同系统外观略有差异。
- `docs/` 下的文档是早期版本的记录，部分内容已过时，以本 README 为准。
