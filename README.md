# 交易物种

PandaAI「苏客松」参赛作品。一个手机可玩的 H5 小游戏：玩家在几个历史投资路口做选择，系统根据选择行为生成「交易物种」人物卡，并给出因人而异的下一步推荐。

## 访问与运行

- 在线（H5）：https://doctors-of-chaos.github.io/trading-species-game/ （开启 GitHub Pages 后生效）
- 本地：下载本仓库，用浏览器打开 `index.html` 即可，手机、电脑均可（推荐 Chrome）。
- 不需要账号，不需要安装，没有构建步骤，运行时不联网。

## 玩法

- 新手模式：6 个历史路口（2004 腾讯上市、2008 北京楼市、2010 比特币、2015 英伟达、2020 疫情暴跌、2021 元宇宙热潮），每关选一张图标卡片，随后「时间倒带」揭晓结果。
- 进阶模式：5 个隐去指数名称和年份的真实行情盲盒，选择明日仓位和决策依据。
- 结算页：人物卡（猎豹 / 大象 / 狐狸 / 熊猫）、四维画像（风险承受、纪律性、逆向冷静、引导需求）、「判断有多稳」（证据不足时可再答一题修正）、个性化推荐及推荐理由。
- 画像依据玩家的选择、决策依据和用时，不以收益高低作为评价标准。

## 隐私与数据安全

- 不收集任何个人信息。页面没有网络请求，也不写入本地存储或 Cookie；所有计算在玩家自己的浏览器里完成，关闭页面即消失。
- 没有分享功能。人物卡与原始选择记录只显示在玩家本机，不会被上传或自动公开。
- 仓库不包含任何账号、密码或数据访问密钥。

## 第三方组件、开源项目与 AI 工具

- 运行时：无第三方库、无 CDN、无外部字体。文字使用系统字体，部分图标为系统 emoji；角色与道具为自绘 SVG。
- 数据：进阶模式行情最初通过开源项目 [AKShare](https://github.com/akfamily/akshare) 获取，后用 Panda Data（`panda_data` SDK）核对。
- AI 工具：使用 Claude Code（Anthropic）辅助编写与重构代码、绘制 SVG 角色、自动化测试与数据核对。
- 早期原型：`archive/` 中的早期版本含 ZCODE 可视化组件的占位代码，所用工具与用途：**待作者确认**。
